# 随手清单 · MIT

独立页面插件示例，只依赖公开 SDK，不读取 Nous 或下载器源码。

运行 `node sdk/dev.mjs .` 打开预览，验证新增、完成、删除和菜单切换；运行 `node sdk/check.mjs .` 检查；运行 `node sdk/pack.mjs .` 打包。当前 ID 使用 `.dev` 后缀供本机开发；正式发布前设置自己的命名空间、仓库地址与版本。

原生客户端测试：在插件管理 → 开发插件启用当前账户的本机开发模式，填入 `http://127.0.0.1:8088/`，读取并确认存储权限。Android 使用 `adb reverse tcp:8088 tcp:8088`。开发模式来源不进入正式签名插件目录。
